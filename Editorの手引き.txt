【Editorの使い方】

・エディターモードに入る/出る	→	B

・カメラ操作			→	右クリック＋マウス操作

・移動操作			→	右クリック＋WASDEQ(前後左右上下)

・オブジェクトを生成する	→	X

・生成するオブジェクトの変更	→	矢印キー左右(→で次のオブジェクト左で前のオブジェクト)

・オブジェクトを選択する	→	オブジェクトを左クリック

　　→ポジション変更		→	選択状態でW→ギズモ(矢印)をスライド

　　→　スケール変更		→	選択状態でE→ギズモ(矢印)をスライド

　　→ローテ―ト変更		→	選択状態でR→ギズモ(矢印)をスライド

・オブジェクトをコピーする	→	ALT＋ギズモ(矢印)をスライド

・オブジェクトの選択を解除	→	選択状態でL

・オブジェクトを削除		→	選択状態でDelete

・生成オブジェクトの切り替え	→	矢印キー左右(→で次のオブジェクト、←で前のオブジェクト)

・プレイヤーを注視点に移動	→	中クリック(ステージを途中からプレイしたい場合などに便利)

・スナップサイズを変更		→	矢印キー上下(↑で+0.1、↓で-0.1)シフト同時押しで1.0

・保存するステージの切り替え　→	数字キー1と2(1で-1、2で+1)

・ステージを保存する		→	Ctrl＋S

・ステージを切り替える		→	Ctrl＋O(左上に数字が出るのでキーボード入力後Enterで切り替え)
